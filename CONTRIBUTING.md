# Contributing

## Documentation consistency rules

When editing docs, keep these files aligned:
- `README.md`
- `README-CN.md`
- `SKILL.md`
- `references/*.md`

## Core boundary

Keep project positioning stable:
- Core output: `main.tex`
- Optional output: compiled PDF

## Pull request checklist

- Update both English and Chinese README with equivalent content.
- Verify project structure section matches actual files.
- Ensure templates and SKILL environment names stay consistent.
- Add or refresh examples when behavior rules change.
